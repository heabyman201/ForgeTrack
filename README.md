ForgeTrack
A basic fitness tracking app I built for fun. You log workouts, it saves them, there's a rest timer. Nothing special.
Built with Kotlin and Jetpack Compose. Code quality is ass , it's a hobby project, not a production app. I learned a lot making it and that was kind of the point.
Feel free to poke around.
